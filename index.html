How the keyboard polling works

  • The program loops forever, reading RAM[24576] (the keyboard register).
  • Any key makes it non-zero, so the colour variable is set to -1 (all 16 bits on, black). Otherwise it is set to 0 (white).
  • It then repaints 20 words starting at 18176, adding 32 after each word to reach the next row.
  • The emulator writes 65 into RAM[24576] only while a key or pointer is physically held, and 0 otherwise. Nothing latches.
